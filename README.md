## 🙋 About Me

I'm Mateo, a developer who enjoys building useful software, polished interfaces, and reliable systems. I work primarily with **TypeScript**, alongside Java, Kotlin, and systems programming.

- 🔭 **Working on:** [LazyDesktop](https://github.com/VOMLabs/lazydesktop/), [VoxelVein](https://github.com/VoxelVein/frontend), Ferrum
- 🌱 **Learning:** Rust and C++
- 💬 **Ask me about:** TypeScript and web development
- 🎨 **Also into:** Pixel art
- 📫 **Find me:** [Devflare Discord](https://dc.devflare.de) or [VOMLabs Discord](https://dsc.gg/vomlabs)
- 😄 **Pronouns:** He/Him

## 🚀 Projects

### 🔌 Minecraft Plugins

- **[ServerGuard](https://github.com/VOMLabs/serverguard/)*:** Per-world protection for modern Minecraft servers, evolving from [CraftGuard](https://modrinth.com/plugin/craftguard).
- **PartySystem:** A private plugin for the VOMLabs Minecraft network.

### 🛠️ Software & Systems

- **[LazyDesktop](https://github.com/VOMLabs/lazydesktop/)*:** A free, native Git GUI built with Rust and C++.
- **Ferrum:** An experiment exploring a Minecraft rewrite in Rust and `bevy`.

### 🌐 Web Applications

- **[SumoxGames](https://www.sumox.net/):** A customized platform built with Next.js and shadcn/ui, using [BeUI](https://beui.dev).
- **PumaPanel:** An open-source, self-hostable Pterodactyl-alternative built from scratch w/ Next.js and Rust.
